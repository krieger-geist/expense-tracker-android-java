# Expense Tracker App 📱💰

A modern Android Expense Tracker application built using Java and Android Studio.  
This application helps users manage their daily expenses efficiently with a clean Material Design UI and smooth user experience.

---

# 🚀 Features

✅ Add New Expenses  
✅ View Expense List  
✅ Delete Individual Expenses  
✅ Delete All Expenses  
✅ Calculate Total Expense Automatically  
✅ Material Date Picker Integration  
✅ RecyclerView Expense Listing  
✅ Bottom Navigation UI  
✅ Modern Material Design Interface

# ⚙️ How the App Works

## ➕ Add Expense Module

Users can:
- Enter expense title
- Enter amount
- Enter category
- Select date using Material Date Picker
- Save expense details

---

## 📋 View Expense Module

Users can:
- View all expenses
- See amount and date
- Scroll through expenses using RecyclerView
- Check total expense amount

---

## 🗑️ Delete Functionality

Users can:
- Long press on expense item to delete
- Delete all expenses using confirmation dialog

# ⚙️ Installation Guide

## 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/expense-tracker-android-java.git
```

---

## 2️⃣ Open in Android Studio

- Open Android Studio
- Click on "Open Project"
- Select project folder

---

## 3️⃣ Sync Gradle

Allow Android Studio to sync all dependencies.

---

## 4️⃣ Run Application

Run app on:
- Android Emulator
- Physical Android Device
